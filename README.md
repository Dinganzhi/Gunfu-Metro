## 滚服地铁是什么？

滚服地铁是一个由mc_desk, Dinganzhi, Zhongyicheng，在2025年8月10日创建并管理的一个集团，目的是为了在服务器内建立庞大的轨道交通网络系统。其在建立时接管了服务器内的铁路，并在2025年8月15日开通了首条地铁线路1号线。到目前为止，其有近乎覆盖全服的广大线路网，包含地铁，铁路和市域铁路，并还在继续建设。

## 网站的历史和作用？

网站于2025年9月1日开始运营，在一开始的时候配置网络示意图。随后几个月网站便停止了更新。一直到2026年2月2日，网站迁移到了Cloudflare托管并再一次活跃。现在，网站有中英双语，多个功能，且还在开发的路上。

## 为什么要开源？

开源并不是为了把网站作为模版分享（当然你也可以下载下来用），而是为了让大家更好的指出里面的错误，或者优化代码。如果你想要引用网站作为模版自己使用，你可以选择不加任何来源和声明，但是如果你想要使用里面的功能，请在显著位置标记来源和本仓库链接。
